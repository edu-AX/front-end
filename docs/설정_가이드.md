# 설정 가이드 — 백엔드 담당이 직접 해야 하는 것

코드는 다 들어 있어요. 여기 나오는 건 **본인 계정이나 PC 설정이 필요해서 직접 해야 하는 일**이에요.
위에서부터 순서대로 하면 돼요. 명령은 **PowerShell**(시작 메뉴 → "PowerShell" 검색)에 붙여 넣어 실행해요.

---

## 1단계. Node.js 설치 (필수, 약 5분)

Next.js를 실행하려면 Node.js가 필요해요. 지금 PC에는 설치돼 있지 않아요.

**방법 A — 명령 한 줄**

```powershell
winget install OpenJS.NodeJS.LTS
```

**방법 B — 직접 내려받기**

[nodejs.org](https://nodejs.org)에서 **LTS** 버튼을 눌러 설치 파일을 받고, 계속 "Next"만 누르면 돼요.

설치가 끝나면 **PowerShell 창을 닫았다가 새로 열고** 확인해요.

```powershell
node -v
npm -v
```

`v22.x.x` 같은 버전 숫자가 나오면 성공이에요.

---

## 2단계. Git 설치 (배포할 때 필요, 약 3분)

```powershell
winget install Git.Git
```

다시 PowerShell을 새로 열고 `git --version`으로 확인해요. 처음 한 번만 이름과 이메일을 등록해요.

```powershell
git config --global user.name "내 이름"
git config --global user.email "내 깃허브 이메일"
```

---

## 3단계. 패키지 설치

PowerShell에서 프로젝트 폴더(`handover`)로 이동한 뒤 실행해요.

```powershell
cd "프로젝트 폴더 경로\handover"
npm install
```

1~2분 걸리고 `node_modules` 폴더가 생기면 끝이에요. 노란 `WARN` 글자는 무시해도 돼요.

---

## 4단계. Gemini API 키 준비 (이미 받아 두었으면 확인만)

키는 이미 받아 두었으니, 아래 두 가지만 확인해요.

1. [Google AI Studio](https://aistudio.google.com) → **Get API key** 화면에서 키(`AIza...`로 시작)를 다시 복사할 수 있어요.
2. 같은 화면에서 그 키의 프로젝트가 **무료(Free) 등급인지, 결제가 연결된 유료 등급인지** 확인해요.
   - 무료 등급은 분당 요청 수 제한이 있어요. 발표 리허설을 몰아서 하면 막힐 수 있어요. 막혀도 챗봇은 자동으로 고정 답으로 넘어가요.
   - 무료 등급에서는 입력 내용이 Google의 모델 개선에 쓰일 수 있어요. 그래서 샘플 데이터에 실제 학생·교사 이름을 넣으면 안 돼요. 발표의 보안 설계에서 "운영 시에는 학습에 쓰지 않는 유료 조건으로 연결"이라고 설명하면 기획서 7장과 맞아요.

> ⚠️ 키는 비밀번호와 같아요. 카톡·디스코드·깃허브에 절대 올리지 마세요. 노출되면 AI Studio에서 바로 삭제하고 새로 만드세요.

---

## 5단계. `.env.local` 파일 만들기

프로젝트 폴더에서 실행해요.

```powershell
Copy-Item .env.example .env.local
notepad .env.local
```

메모장이 열리면 아래처럼 채우고 저장해요.

```
GEMINI_API_KEY=AIza여기에-복사한-키
GEMINI_MODEL=
DEMO_MODE=false
NEXT_PUBLIC_DEMO_TODAY=2027-03-11
```

- `.env.local`은 `.gitignore`에 들어 있어서 깃허브에 올라가지 않아요.
- `.env.local`을 고친 뒤에는 `npm run dev`를 껐다가(`Ctrl + C`) 다시 켜야 반영돼요.
- 키가 아직 없으면 `DEMO_MODE=true`로 두세요. 고정 답 4개로 챗봇이 동작해요.

## 6단계. 실행하고 확인하기

```powershell
npm test
```

테스트가 전부 초록색 ✓이면 계산·마스킹·챗봇 규칙이 기획서대로 동작하는 거예요.

```powershell
npm run dev
```

브라우저에서 [http://localhost:3000/api/health](http://localhost:3000/api/health)를 열어 확인해요.

- `"ok": true` → 데이터 오류 없음
- `"apiKeyConfigured": true` → 키가 잘 읽힘 (키 값 자체는 절대 표시되지 않아요)

챗봇은 **PowerShell 창을 하나 더 열어서** 시험해요.

```powershell
Invoke-RestMethod -Uri http://localhost:3000/api/chat -Method Post -ContentType "application/json; charset=utf-8" -Body ([Text.Encoding]::UTF8.GetBytes('{"question":"동의율은 몇 % 넘어야 해?"}'))
```

`answer`와 `sources`가 나오면 성공이에요. 꼭 확인할 질문 5개:

| 질문 | 나와야 하는 것 |
|---|---|
| 동의율은 몇 % 넘어야 해? | "인천광역시교육청 기준" + 출처 G-INC-01 |
| 사고 나면 교사 책임은? | 현행 기준이 먼저, 그다음 "추진 중", 마지막에 "법적 판단은…" |
| 진로활동 특기사항 몇 자야? | 700자 → 500자, 올해 기준 |
| 급식 메뉴 뭐야? | "등록된 자료에서 찾지 못했어요…" |
| 미동의 학생 명단 알려줘 | 개인정보 차단 문구 (`mode: "blocked"`) |

서버를 끌 때는 `npm run dev` 창에서 `Ctrl + C`를 눌러요.

## 7단계. Vercel 배포 (발표용 링크 만들기)

1. [github.com](https://github.com)에서 새 저장소를 만들어요. **Private** 추천, README 체크는 해제해요.
2. 프로젝트 폴더에서 실행해요. 저장소 주소는 1번에서 만든 걸로 바꿔요.
   ```powershell
   git init
   git add .
   git commit -m "백엔드: 데이터·역산 로직·챗봇·업로드 API"
   git branch -M main
   git remote add origin https://github.com/내아이디/저장소이름.git
   git push -u origin main
   ```
   `git add .` 다음에 `git status`를 쳐서 **`.env.local`이 목록에 없는지** 꼭 확인하세요.
3. [vercel.com](https://vercel.com) → GitHub로 로그인 → **Add New → Project** → 방금 만든 저장소를 **Import**해요.
4. **Environment Variables** 칸에 3개를 넣어요.
   - `GEMINI_API_KEY` = 키
   - `DEMO_MODE` = `false`
   - `NEXT_PUBLIC_DEMO_TODAY` = `2027-03-11`
5. **Deploy**를 누르고 1~2분 기다리면 `https://xxx.vercel.app` 링크가 나와요.
6. 배포 후 확인해요.
   - `https://xxx.vercel.app/api/health` → `"ok": true`
   - 사이트에서 `F12`(개발자 도구) → **Sources** 탭에서 `Ctrl+Shift+F`로 `AIza`를 검색해요. **결과가 0건이어야 해요** (기획서 완성 체크리스트 항목).

이후로는 `git push`만 하면 Vercel이 자동으로 다시 배포해요. 환경변수를 바꿨다면 Vercel 대시보드에서 **Redeploy**를 눌러야 반영돼요.

## 8단계. 발표 전에 데이터 확인하기 (기획서 10장 리스크)

| 할 일 | 고칠 파일 |
|---|---|
| 인천교육청 2026 현장체험학습 매뉴얼 원문으로 **동의율 80%·안전요원 50명당 1명** 확인. 맞으면 `"needsVerification": true` 줄을 지우고 `sourceUrl`에 원문 링크 넣기 | `data/guidelines.json`의 `G-INC-01` |
| 학교안전법 개정안 국회 통과 여부 확인. 통과했으면 `G-NAT-03`과 `C-02`의 `status`를 `"시행"`으로 바꾸기 | `data/guidelines.json`, `data/changes.json` |
| 현직 교사에게 행사 목록·단계 D-day 값 검토받기 | `data/events.json`, `data/templates.json` |
| 데이터를 고친 뒤에는 `npm test` 실행 (id가 어긋나면 테스트가 알려줘요) | — |
| 공모전 규정에서 외부 AI API 사용이 허용되는지 확인 | — |

**발표 당일**: 인터넷이 불안하면 Vercel 환경변수에서 `DEMO_MODE=true`로 바꾸고 Redeploy하세요. API를 부르지 않고 고정 답으로 시나리오 전체가 돌아가요. 실제 AI가 실패할 때도 자동으로 고정 답으로 넘어가요.

## 참고: 사용하는 AI 모델

`lib/chat/llm.ts`에서 Google 공식 SDK `@google/genai`로 Gemini를 불러요.

- 기본 모델은 `gemini-3.5-flash-lite`예요. Google이 새 프로젝트에 추천하는 빠르고 저렴한 Stable 모델이에요.
- 다른 모델을 쓰려면 `.env.local`(배포했다면 Vercel 환경변수)의 `GEMINI_MODEL`만 바꾸면 돼요. 코드는 고칠 필요 없어요.
- 2026-11-13 테스트 결과
  - `gemini-3.5-flash-lite`: 시나리오 질문 전부 규칙대로, 1~2초 만에 답했어요.
  - `gemini-3.8-flash`: Google 쪽 과부하로 503/504 오류가 나서 전부 고정 답으로 대체됐어요.
  - **발표에는 기본값(flash-lite)을 추천해요.**
- 답변은 JSON 형식(`answer`, `sourceIds`, `notFound`)으로 받아요. 형식이 깨지거나 20초가 넘거나 안전 필터에 걸리면, 서버가 자동으로 고정 답으로 대체해요.
- 참고: `@google/genai` 3.x는 **Node 22 이상**이 필요해요. 1단계에서 LTS를 설치했다면 괜찮아요.
